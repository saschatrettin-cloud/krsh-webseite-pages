Interner Prototyp

Pilates-Anmeldung

Der Prototyp bildet zwei getrennte Anmeldelisten fuer Dienstag und Donnerstag ab. Sichtbar sind Teilnehmer, Restplaetze und der automatische Wochenwechsel nach Kursende.

10 Plaetze je Termin
2 separate Anmeldelisten
13:30 Uhr automatischer Wochenwechsel

Zielbild

Schlanke Loesung ohne grosses System

Die sichtbare Bedienoberflaeche ist bereits vorbereitet. Solange noch keine externe API hinterlegt ist, laeuft die Seite im gekennzeichneten Demo-Modus mit lokaler Browser-Speicherung.

Produktiv sinnvoll

Astro-Seite fuer die Anzeige, kleine geschuetzte API fuer die gemeinsame Datenspeicherung.

Datensparsam

Fuer den Start genuegt der Name je Anmeldung. Weitere Angaben sind derzeit nicht erforderlich.

Automatischer Reset

Nach Dienstag bzw. Donnerstag 13:30 Uhr springt die Anmeldung automatisch auf die Folgewoche um.

Anmeldeansicht

Wochenlisten fuer beide Kurstermine

Die nachstehende Ansicht zeigt die spaetere Nutzerfuehrung bereits in der Website. Im Demo-Modus ist der Stand nur im aktuellen Browser sichtbar.

Lade Anmeldestand...

Hinweise

  • Die Anmeldung gilt jeweils nur fuer den naechsten Kurstermin.
  • Nach Kursende springt das System automatisch auf die Folgewoche um.
  • Im Produktivbetrieb darf die Seite nur intern mit Zugriffsschutz freigeschaltet werden.
